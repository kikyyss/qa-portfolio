**Требования: страница корзины [saucedemo.com](http://saucedemo.com).**

**Контекст**  
Пользователь находится на странице добавления товара в корзину авторизованным через логин Standartuser ([saucedemo.com/inventory.html](https://www.saucedemo.com/inventory.html))

**Функциональные требования**

1. Товар должен добавляться в корзину через кнопку “Add to cart”  
2. Товар должен удаляться из корзины кнопкой “Remove”  
3. Кнопка Checkout должна перенаправлять на страницу “Ввода информации”  
4. Кнопка “Continue Shopping” должна перенаправлять пользователя в каталог   
5. Иконка корзины должна отображать корректное количество добавленных товаров  
6. Корзина должна отображать название, цену и значение QTY (равное 1\) для каждого товара   
7. При пустой корзине должно быть корректное отображение   
8. Товары, добавленные в корзину, должны сохраняться при переходе между страницами   
9. Кнопка "Remove" должна удалять именно тот товар, на котором её нажали   
10. При нажатии на название товара в корзине, пользователь должен перенаправляться на страницу описание товара  
11. Товары в корзине должны сортироваться сверху вниз по дате добавления
