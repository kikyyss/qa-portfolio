**Требования: Checkout**

**Контекст**  
Пользователь находится на странице оплаты, после добавления товаров в корзину ([saucedemo.com/checkout-step-one.html](http://saucedemo.com/checkout-step-one.html))

**Функциональные требования**

1. При заполнении всех обязательных полей и нажатии кнопки 'Continue' система должна перенаправить пользователя на /checkout-step-two.html   
2. При попытке продолжить с пустым полем 'First Name' система должна отобразить ошибку 'Error: First Name is required'   
3. При попытке продолжить с пустым полем 'Last Name' система должна отобразить ошибку 'Error: Last Name is required'   
4. При попытке продолжить с пустым полем 'Zip/Postal Code' система должна отобразить ошибку 'Error: Postal Code is required'   
5. При одновременно пустых нескольких обязательных полях система должна отобразить ошибку только по первому в порядке проверки полю   
6. Поля First Name, Last Name и Zip/Postal Code должны принимать ввод без ограничения по количеству символов    
7. Поля First Name, Last Name и Zip/Postal Code должны принимать ввод без ограничения по специальным символам  
8. Кнопка 'Cancel' на странице step-one должна перенаправлять на /cart.html   
9. При попытке перейти на страницу /checkout-step-two.html без прохождения step-one система должна пропустить пользователя на step-two и отобразить товары из его корзины  
10. При переходе на /checkout-step-two.html система должна отображать товары, добавленные в корзину   
11. При переходе на /checkout-step-two.html система должна отображать цену каждого товара, налог и итоговую сумму  
12. Total на странице Overview должен равняться сумме Item total и Tax для любого набора товаров в корзине   
13. Кнопка “Finish” должна перенаправить пользователя на страницу /checkout-complete.html  
14. Кнопка 'Cancel' на странице step-two должна перенаправлять пользователя на /inventory.html   
15. На странице /checkout-complete.html, кнопка “Generate PDF order” должна скачивать файл о заказе  
16. Кнопка “Back Home” должна перенаправить пользователя на /inventory.html  
17. Система должна очищать содержимое корзины после успешного оформления заказа
