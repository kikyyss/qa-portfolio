**Требования: [demoqa.com/automation-practice-form](http://demoqa.com/automation-practice-form) поле “Mobile Number” и “Email”**  
**Контекст**  
Пользователь находится на странице [demoqa.com/automation-practice-form](http://demoqa.com/automation-practice-form), Student Registration Form.

**Функциональные требования**

1. При вводе в поле Mobile Number ровно 10 цифр и заполнении остальных обязательных полей, система должна успешно отправить форму (появляется модальное окно с введенными данными)   
2. При вводе в поле Mobile Number значения длиной менее 10 цифр система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
3. При вводе в поле Mobile Number значения длинной более 10 цифр система физически не дает вводить большее количество  
4. При вводе в поле Mobile Number букв или специальных символов система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
5. При пустом поле Mobile Number символов система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
6. При вводе в поле Email корректных данных система должна успешно отправить форму (появляется модальное окно с введенными данными)   
7. Пустое поле Email не является обязательным для заполнения форма отправляется успешно даже при пустом значении  
8. При вводе в поле Email корректных данных без спецсимвола “@”  система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
9. При вводе в локальную часть email (до '@') символов вида `/`, `"`, `#` и аналогичных, система должна подсветить поле красной рамкой и не должна отправлять форму   
10. При вводе в поле Email без домена после “@” система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
11. При вводе в поле Email без точки в домене система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
12. При вводе в поле Email после точки в домене, значение ровно 2 символам система должна успешно отправить форму (появляется модальное окно с введенными данными)  
13. При вводе в поле Email после точки в домене значение менее 2 символов система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)   
14. При вводе в поле Email после точки в домене значение более 2 символов система должна успешно отправить форму (появляется модальное окно с введенными данными)   
15. При вводе в поле Email после точки в домене цифр или специальных символов система должна подсветить поле красной рамкой и не должна отправлять форму (модальное окно с данными не появляется)
