Пользователь находится на странице авторизации.

1. Поля "Username" и "Password" обязательны для заполнения.  
2. Пользователь должен ввести один из предоставленных Username и соответствующий Password.   
3. При вводе корректных учётных данных система должна выполнить авторизацию пользователя и перенаправить его на страницу каталога товаров.  
4. Если введены некорректные учетные данные, система должна отобразить ошибку “Epic sadface: Username and password do not match any user in this service”.  
5. Если поле "Username" не заполнено система должна отобразить ошибку "Epic sadface: Username is required" и не выполнять авторизацию.  
6. Если поле "Password" не заполнено система должна отобразить ошибку "Epic sadface: Password is required" и не выполнять авторизацию.  
7. Если оба поля "Username" и "Password" не заполнены система должна отобразить ошибку "Epic sadface: Username is required" и не выполнять авторизацию.
